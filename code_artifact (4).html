인터넷 링크(QR코드) 클릭 한 번으로 모든 기기에서 실행되는 소프트웨어.

핵심 개념 02

바이브 코딩
(Vibe Coding)

개발 문법을 외우는 대신,
자연어로 AI에게 시스템의 목적과 분위기(Vibe)를 지시하여 코드를 생성하는 방식.

교사의 새로운 역할

코더 (타이피스트)

시스템 아키텍트 (설계자)

코드는 AI가 짭니다. 선생님은 교육적 목적 설계에 집중하세요.

핵심 개념 03

API 란 무엇인가?

  • Application Programming Interface
  • 소프트웨어들이 서로 대화하는 연결 통로
  • 우리가 만든 웹앱 화면(껍데기)과 초거대 AI(뇌)를 연결하는 다리 역할.

비유하자면

API는 식당의 '종업원' 입니다.

우리 학교 앱

손님 (주문자)

API

종업원 (전달자)

OpenAI 서버

천재 요리사

잠깐, 구글(Gemini)은 완전 무료인데
왜 굳이 OpenAI API를 쓸까요?

OpenAI API를 쓰는 3가지 이유

1. 압도적 표준화

AI 코딩 도구들이 OpenAI 문법을 너무 잘 알아서 에러 없는 완벽한 코드를 단번에 짜냅니다.

2. 직관적인 코드

단일 HTML 파일 안에서 가장 깔끔하고 짧게 통신 로직이 구현됩니다.

3. 방대한 자료

오류가 나도 인터넷에 해결책과 레퍼런스가 가장 많습니다.

오늘의 미션

OpenAI API를 연동하여
우리 반/교과에 딱 맞는 맞춤형 AI 챗봇 만들기

Step 1. 기획

챗봇의 영혼,
시스템 프롬프트 (System Prompt)

AI에게 부여하는 '절대 규칙'이자 '자아(Persona)'.
사용자에게는 보이지 않지만, AI의 모든 답변 스타일과 성격을 지배합니다.

교과별 페르소나 설계 예시

📜 국어과

윤동주 시인 챗봇:
무조건 시적인 은유로만 대답하고, 시대를 고뇌하는 말투 사용.

📐 수학과

소크라테스 튜터:
학생이 정답을 물어보면 화를 내고, 질문을 통해 스스로 풀도록 유도함.

💡 진로/상담

공감 요정:
무조건 학생의 말에 3문장 이상 깊이 공감해 준 뒤에 조언을 시작함.

Step 2. 바이브 코딩

마법의 프롬프트 복사하기

[역할] 당신은 뛰어난 프론트엔드 개발자입니다. 단일 HTML 파일로 '맞춤형 AI 챗봇 웹앱'을 만들어주세요.

[기능] 1. 모바일 최적화 채팅창 UI
2. OpenAI API 연동 (fetch 함수, gpt-4o-mini 모델)
3. const API_KEY = "여기에_키_입력"; 변수를 최상단에 배치
4. const SYSTEM_PROMPT = "성격"; 변수를 시스템 프롬프트로 전송

Step 3. 디자인 튜닝

"말풍선을 카카오톡처럼
동글동글하고 노란색으로 바꿔줘."

자연어로 원하는 UI/UX를 끊임없이 요구하세요.

Step 4. 생명 불어넣기

화면의 임시 API 키를
코드 최상단에 붙여넣으세요.

이제 껍데기가 지능을 갖게 됩니다.

호스팅(Hosting)의 필요성

"컴퓨터에 있는 HTML 파일을
어떻게 스마트폰에서 켜나요?"

인터넷 주소(URL)와 QR코드를 만들어야 합니다.

주의사항 (다크 패턴)

결제 유도창에 당황하지 마세요.

  • 파일을 올릴 때 'Start free trial'이라는 파란 버튼이 뜹니다.
  • 이 버튼을 절대 누르지 마세요. (유료 요금제 유도)
  • 아래에 숨어있는 'Skip' 글자나 우측 상단의 'X'를 누르면 평생 무료입니다.

보안 부채 (Security Debt)

가장 중요한 보안 이야기

HTML에 API 키를 넣으면 생기는 일

우리가 만든 방식(Client-side)은 브라우저에서 'F12(개발자 도구)'를 누르면 누구나 API 키를 훔쳐볼 수 있습니다.
